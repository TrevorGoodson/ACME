# Intuition
When a function is differentiable, and its derivative is continuous. A derivative can never have just a jump (Darboux's theorem), so examples of functions with non-continuous derivatives are kind of crazy, like $f(x) = x^2sin(1/x)$.

If a function is continuously differentiable, then you can write $f \in C^1$. If the function is $k$ times differentiable, and each derivative is continous, you can write $f \in C^k$.
