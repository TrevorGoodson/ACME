#Definition 
## Intuition
You can think of the argument maximizer as a function that takes in a set and spits out the element of the set that makes a function on that set the largest it can be
## Technical Details
###### Assumptions
$X$ is any set
$f:X \to \mathbb R$
$Y \subset \mathbb R$ is the [[Image]] of $f$
$x,y \in X$
$\max$ is the [[Maximum]]
###### Definition
The argument maximizer of $X$ with regards to $f$ satisfies 
$\underset{X}{\text{argmin}}\ f(x) = y$ such that $f(y) = \max(Y)$
