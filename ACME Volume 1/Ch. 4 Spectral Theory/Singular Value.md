#Definition Theorem 4.5.10

The singular values, $\sigma_i$ of a matrix $A$ is the diagonal entries of $\Sigma$ in $A = U \Sigma V^H$ ([[Singular Value Decomposition]]) (except for any 0 values). 

The singular values are ordered in $\Sigma$

The singular values equal the square root of the [[Eigenvalue|eigenvalues]] of $A^TA$
