#Definition Definition 8.1.2
## Intuition
A subdivision is a way to chop up an [[n-Interval]]. Into smaller, but of equal dimension, n-intervals. Think cutting a cube into smaller cubes. Or a square into smaller squares. You a set of cuts for each dimension.

## Key Results
- A subdivision can be used to define a set of n-intervals that make up the main n-interval (Definition 8.1.3)
