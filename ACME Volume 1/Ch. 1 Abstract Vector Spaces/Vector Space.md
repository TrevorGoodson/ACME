#Definition Definition 1.1.1

A space, $V$, with addition and scalar multiplication defined
It also has the following properties
$x,y \in V$
$a,b \in \mathbb F$
Addition satisfies these properties
- $x+y = y+x$
- $(x+y)+z = x+(y+z)$
- $\exists 0 \in V$ such that $0+x = x$
- For every $x$, $\exists\ {-x}$ such that $x + (-x) = 0$
Scalar Multiplication satisfies these properties
- $a(x+y) = ax + ay$
- $(a+b)x = ax+bx$
- $1x = x$
- $(ab)x = a(bx)$
