#Definition  Definition 1.3.1
# Technical Definition
###### Declarations
$A \subset \mathbb R$
$B \subset \mathbb R_{\ge 0}$
$a \in A$
$b, c \in \mathbb R$


###### Definition
$A$ is bounded above if $b$ exists such that $a \le b$ for all $a \in A$. If so, $b$ is an upper bound for $A$.

$A$ is bounded below if $c$ exists such that $c \le a$ for all $a \in A$. If so, $c$ is a lower bound for $A$.

The set $B$ is defined to be bounded if it has an upper bound.
