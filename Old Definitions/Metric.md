# Technical Definition
###### Symbols
$X$ is any set
$x, y, z \in X$
$d: X \times X \to \mathbb R$

###### Definition
$d$ is a metric of $X$ if it satisfies:
1. Positive Definiteness: $d(x,y) \ge 0$, $d(x,y) =0 \Leftrightarrow x=y$
2. Symmetry: $d(x,y) = d(y,x)$
3. Triangle Inequality: $d(x,y) \le d(x,z) + d(z,y)$
$(X, d)$ is a metric space

# Key Results
- Every [[Norm]] defines a metric ($||x-y||$), but not every metric can be defined by a norm
