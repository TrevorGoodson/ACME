# Convex Set
#Definition Definition 13.1.1
## Technical Details
###### Assumptions
$V$ is a [[Vector Space]]
$C \subset V$ is the candidate for being convex
$C$ is non-empty
$x,y \in C$
$\lambda \in \mathbb [0,1]$
$\mathscr l(x,y) = \{ \lambda x + (1-\lambda)y \}$  is a line segment between $x$ and $y$

###### Definition
$C$ is defined as being convex if the following holds for all $\lambda$
$$
\mathscr l(x,y) \subset C
$$

## Key Results
- intersection of convex sets is convex (Proposition 13.1.3)
